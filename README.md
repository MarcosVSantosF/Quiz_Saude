# 📘 Quiz Saúde – UBS

Quiz interativo desenvolvido para auxiliar estudantes de enfermagem durante estágio em Unidade Básica de Saúde (UBS). O projeto foi criado sob demanda real e utilizado em sala de aula por uma enfermeira supervisora de estágio.

🔗 **[Acesse o projeto ao vivo →](https://quiz-saude.vercel.app)**

## 💡 Sobre o Projeto

A ideia surgiu de uma necessidade real: criar uma ferramenta de fixação de conteúdo para alunos de enfermagem em estágio na UBS. O quiz apresenta perguntas sobre saúde, procedimentos e boas práticas, com feedback imediato ao aluno ao final de cada sessão.

Este projeto foi **publicado e utilizado em ambiente real**, não apenas como exercício acadêmico.

---

## 🚀 Funcionalidades

- ✅ Perguntas de múltipla escolha sobre saúde e UBS
- ✅ Feedback imediato por questão (certo/errado)
- ✅ Pontuação final ao término do quiz
- ✅ Opção de refazer o quiz
- ✅ Interface responsiva (funciona em celular e desktop)
- ✅ Separação de responsabilidades: perguntas em arquivo dedicado (`questions.js`)

## 📁 Estrutura do Projeto

```
Quiz_Saude/
│
├── index.html        # Estrutura principal da página
├── style.css         # Estilos e responsividade
├── quiz.js           # Lógica do quiz (controle de fluxo, pontuação)
├── questions.js      # Banco de perguntas separado da lógica
└── imagens/          # Assets de imagem
```
